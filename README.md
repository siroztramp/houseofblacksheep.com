# houseofblacksheep.com

Standalone HOBS Creative House website, migrated from the Creative House implementation.

Requires Node.js 20.19+ or 22.12+ (the repository pins Node 22.23.1 in `.nvmrc`).

Routes:

- `/` — Creative House home
- `/approach/` — House profile
- `/services/` — Services and proven work
- `/contact/` — Contact and connection yard

Run locally with `npm run dev` and build with `npm run build`. In Vercel, set this folder as the project root.
